# المنظومة الرقمية — نادي الأهلي · الاتحاد الحلبي

عرض تقديمي تفاعلي (بأسلوب PowerPoint) لمشروع التحول الرقمي الشامل للنادي:
**Digital Club Operating System** — من المالية أولًا إلى الإدارة والتشغيل والرياضة والقنوات الرقمية.

## التشغيل

الموقع ملفات ثابتة بلا أي خطوة بناء. الخط (Cairo) مضمَّن محليًا، فيعمل العرض دون اتصال بالإنترنت.

- افتح `index.html` مباشرة في المتصفح، أو
- شغّل خادمًا محليًا: `npx http-server .` ثم افتح `http://localhost:8080`
- للنشر: فعّل **GitHub Pages** على هذا الفرع (المجلد الجذر).

## التحكم

| المفتاح | الوظيفة |
|---|---|
| `←` / `Space` / `PageDown` | الشريحة التالية |
| `→` / `PageUp` | الشريحة السابقة |
| `Home` / `End` | البداية / النهاية |
| `F` | ملء الشاشة |
| زر الماوس الأيسر / الأيمن | التالي / السابق |
| ضغطة عجلة الماوس | التنقل بين خيارات الشريحة |
| `G` | فهرس الشرائح |
| `P` | طباعة / حفظ PDF (شريحة لكل صفحة) |

على الهاتف أو الجهاز اللوحي: السحب يمينًا ويسارًا. ويمكن فتح شريحة محددة عبر الرابط، مثل `index.html#11`.

## المحتوى (37 شريحة في 6 محاور)

1. **الواقع الحالي**: الرصد الميداني، والأثر على الإدارة.
2. **الرؤية**: هدف العشرين ثانية (تفاعلي)، ونظام التشغيل الرقمي، وواجهتا التشغيل والإدارة.
3. **المنظومة**: لوحة الإدارة (مؤشرات قابلة للضغط + رسم التدفق النقدي)، المالية، مراكز التكلفة والموازنة (منزلق تنبيهات 70/85/100%)، المستثمرون، العقود، الرواتب (حاسبة)، الرياضة، المشتريات (سيناريو متحرك)، المستودعات والأصول، الحوكمة (محرك موافقات)، المساعد الذكي، الموقع والمتجر (مزامنة المخزون).
4. **البنية التحتية**: الشبكة والإنترنت، الكهرباء والنسخ الاحتياطي 3-2-1، الأجهزة والسيرفر، الانتقال من «الرشيد».
5. **التقنية والتصميم**: البنية التقنية، نظام التصميم، تجربة المستخدم، الأمان.
6. **خارطة التنفيذ**: المراحل الثماني (تفاعلي)، قبل وبعد، الخطوة التالية.

> جميع الأرقام والأسماء في شرائح النماذج **بيانات توضيحية للعرض** وليست بيانات حقيقية للنادي.
