# النظام المالي — نادي الأهلي · الاتحاد الحلبي

نظام محاسبي ومالي متكامل: دليل الحسابات الفعلي للنادي (2,239 حسابًا)، القيود والسندات، دورة الاعتماد، العملات المتعددة،
إقفال الفترات، الترحيل من نظام الراشد، الموازنات ومراكز الكلفة حسب اللعبة، المستثمرون والأقساط، الرواتب، والتقارير المالية.

| المرحلة | المحتوى |
|---|---|
| 1 · الأساس | تسجيل دخول، تحقق بخطوتين (TOTP)، 7 أدوار وصلاحيات، سجل تدقيق غير قابل للتعديل، إعدادات |
| 2 · النواة المحاسبية | قيد مزدوج متوازن بالعملة الأساسية، ترقيم متسلسل بلا فجوات، مسودة ← إرسال ← اعتماد (حد اعتماد + فصل مهام)، عكس القيود، سندات قبض وصرف، أرصدة افتتاحية، أسعار صرف، إقفال الفترات |
| 3 · الترحيل من الراشد | استيراد Excel للدليل والأرصدة والحركات: فحص ← اعتماد (كل شيء أو لا شيء) ← تقرير مطابقة لكل حساب |
| 4 · الإدارة المالية | الموازنات مقابل الفعلي مع تنبيهات، مراكز كلفة (ألعاب وأقسام)، عقود المستثمرين وأقساطها وتحصيلها، الموظفون ومسيرات الرواتب وترحيلها، ميزان المراجعة وقائمة الدخل والميزانية وكشف الحساب وتقارير مراكز الكلفة مع تصدير Excel، لوحة تحكم |

## ضمانات سلامة البيانات (على مستوى قاعدة البيانات)
- سجل التدقيق يرفض أي تعديل أو حذف (Trigger).
- أسطر القيد المرحّل مقفلة؛ القيد المرحّل لا يُحذف ولا يتغير إلا إلى «معكوس».
- كل سطر إما مدين أو دائن وغير سالب (CHECK).
- لا ترحيل في فترة مقفلة؛ لا ترحيل على حساب تجميعي.

## التشغيل للتطوير
```bash
# PostgreSQL 16 محليًا، ثم:
cd api && cp .env.example .env && npm i && npx prisma migrate deploy && npm run db:seed && npm run dev
cd web && npm i && npm run dev          # http://localhost:3000
npm --prefix api run smoke              # اختبار شامل من طرف لطرف (على قاعدة جديدة)
```
المستخدم الأول: `admin` وكلمة المرور من `ADMIN_PASSWORD` (أو الافتراضية في seed) — **غيّرها وفعّل التحقق بخطوتين فورًا.**

## النشر (خادم النادي أو سحابي)
```bash
cp .env.example .env   # ضع كلمات سر قوية
docker compose up -d --build
docker compose exec app npm run db:seed   # مرة واحدة فقط
```
يعمل على المنفذ 4000 (ضعه خلف HTTPS عبر Nginx/Caddy). نسخ احتياطي يومي تلقائي في `backups/` يُحتفظ به 30 يومًا.

## بانتظار النادي
- ملف ميزان المراجعة / الأرصدة من الراشد (xlsx) للترحيل الفعلي.
- اعتماد العملة الأساسية (USD أو SYP) قبل أول ترحيل.
- قائمة المستخدمين وأدوارهم، وقواعد الرواتب (الضرائب، التأمينات 311).
- أسماء الحسابات غير المسماة في الدليل: 34، 341، 41، 412، 413، 413001، 431، 431001.
