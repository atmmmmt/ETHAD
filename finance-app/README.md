# النظام المالي — نسخة أولية (MVP)

تطبيق React لتجربة النظام المالي لنادي الأهلي · الاتحاد الحلبي قبل بناء النسخة الكاملة.

## التشغيل

- **للتجربة الفورية:** افتح `dist/index.html` مباشرة في المتصفح (ملف واحد، يعمل دون إنترنت).
- **للتطوير:** `npm install` ثم `npm run dev`، وللبناء: `npm run build`.

## المحتوى

| الصفحة | ما تفعله |
|---|---|
| لوحة التحكم | السيولة، الواردات والنفقات، العجز/الوفر، المتأخرات، رسم شهري، النفقات حسب اللعبة والبند، التنبيهات |
| دليل الحسابات | الدليل المنقول من «الرشيد» (2,239 حسابًا بنفس الأرقام) كشجرة مع الأرصدة وكشف حساب لكل حساب |
| القيود اليومية | قيد متعدد الأسطر مع تحقق التوازن، بحث وفلترة، عكس القيد بدل الحذف |
| سندات القبض والصرف | سند سريع يُنشئ القيد تلقائيًا |
| الرواتب | الأساسي والبدلات والمكافآت والإضافي، خصم التأخير والغياب والعقوبات والسلف، قسيمة راتب، ترحيل إلى القيود |
| الموازنة | حسب البند المحاسبي وحسب اللعبة (مراكز التكلفة من حسابات 332/339)، تنبيهات 70/85/100% |
| المستثمرون | جدول الدفعات، المتأخر، تسجيل القبض وإنشاء القيد |
| التقارير | ميزان المراجعة بأربعة مستويات، قائمة الواردات والنفقات، الأموال الجاهزة، تصدير Excel وطباعة PDF |
| الإعدادات | قواعد الرواتب، نسخ احتياطي واسترجاع، سجل التدقيق |

## ملاحظات

- دليل الحسابات حقيقي (من ملف الإكسل المُصدَّر). **الحركات والموظفون والمبالغ بيانات توضيحية.**
- البيانات تُحفظ في متصفح الجهاز (localStorage). النسخة الكاملة ستعمل على خادم وقاعدة بيانات PostgreSQL.
- أُضيف حسابان جديدان: `163999` سلف الموظفين، و`220001` الأرصدة الافتتاحية.
